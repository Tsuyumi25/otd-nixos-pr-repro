# OpenTabletDriver Bluetooth NixOS test

This repository provides a pinned NixOS test package for:

- [OpenTabletDriver PR #4672](https://github.com/OpenTabletDriver/OpenTabletDriver/pull/4672)
- [HIDSharpCore PR #31](https://github.com/OpenTabletDriver/HIDSharpCore/pull/31)

It builds OpenTabletDriver directly from the PR source, supplies the patched
HIDSharpCore package through `projectReferences`, and installs the generated
`70-opentabletdriver.rules` through the standard NixOS
`hardware.opentabletdriver` module.

No broad `hidraw` rule or `MODE="0666"` workaround is included.

The NixOS generation is activated with `sudo`. OpenTabletDriver itself then
runs as an unprivileged systemd user service and accesses the tablet through
a per-user `uaccess` ACL.

## Tested scope

The package and NixOS module were tested on two `x86_64-linux` NixOS 26.05
systems. A Wacom CTL-4100WL connected over Bluetooth as PID `0x03C6` was:

- assigned a per-user ACL on its virtual UHID `hidraw` device;
- opened by HIDSharpCore as a regular user;
- detected by OpenTabletDriver as `Wacom CTL-4100WL` using
  `IntuosV2BluetoothReportParser`;
- exposed as an OpenTabletDriver virtual pressure-sensitive input device.

The flake also evaluates packages for `aarch64-linux`. An ARM build and a
hardware test with CTL-6100WL PID `0x03C8` remain pending.

## Before testing

Remove existing custom OpenTabletDriver package overrides and tablet-specific
`services.udev.extraRules`, especially rules containing `MODE="0666"`.

Existing Bluetooth configuration, `hardware.uinput.enable`, and an existing
`boot.kernelModules = [ "uinput" ];` entry may remain.

## Add the NixOS module

Add this repository as an input to the existing host flake. Keep the host's
current `nixpkgs` input and configuration, and merge only the `otd-repro` input
and module below:

```nix
{
  inputs = {
    # Keep the existing inputs.
    otd-repro.url = "github:Tsuyumi25/otd-nixos-pr-repro";
  };

  outputs = inputs@{ nixpkgs, ... }: {
    nixosConfigurations.my-host = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        # Keep the existing host modules.
        ./configuration.nix
        inputs.otd-repro.nixosModules.default
      ];
    };
  };
}
```

Replace `my-host` with the existing NixOS configuration name, then activate a
temporary test generation:

```console
$ sudo nixos-rebuild test --flake .#my-host
```

`nixos-rebuild test` leaves the boot default unchanged. Rebooting returns to
the previous boot generation.

## Connect and test the tablet

After activation:

1. Ensure the `uinput` module is loaded.
2. Power-cycle or reconnect the Bluetooth tablet. This gives the new `hidraw`
   device a fresh udev `add` event.
3. Restart the OpenTabletDriver user service.

```console
$ sudo modprobe uinput
$ systemctl --user restart opentabletdriver.service
```

Run diagnostics to find the tablet's `hidraw` node, then replace `hidrawX`
below with that node:

```console
$ otd getdiagnostics
$ grep -F '0005:056A:03C8' /etc/udev/rules.d/70-opentabletdriver.rules
$ udevadm info --query=property --name=/dev/hidrawX
$ getfacl /dev/hidrawX
$ journalctl --user -u opentabletdriver.service -b --no-pager
$ otd getcurrentlog
```

For a CTL-6100WL using PID `0x03C8`, the expected udev path contains:

```text
/devices/virtual/misc/uhid/0005:056A:03C8.../hidraw/hidrawX
```

The udev properties should include `seat`, `uaccess`, and `udev-acl`. The ACL
must also contain a read/write entry for the active desktop user:

```text
user:<username>:rw-
```

The tags alone do not prove that the ACL was applied, so include both
`udevadm info` and `getfacl` output when reporting a result.
